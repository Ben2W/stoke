## Commands

| Command       | Description                                            |
| ------------- | ------------------------------------------------------ |
| `rig init`    | Scaffold a new rigkit project.                         |
| `rig plan`    | Print the operations rig would perform.                |
| `rig apply`   | Run the operations in the plan.                        |
| `rig run`     | Invoke a named operation on a workspace.               |
| `rig projects`| List workspaces known to the local runtime.            |

## Help

```sh
rig help
rig run --help
```
