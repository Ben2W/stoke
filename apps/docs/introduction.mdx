---
title: "Introduction"
description: "Rigkit is a CLI and engine for building forkable development workflows from typed task graphs and provider-owned artifacts."
---

`rig` lets you describe a development workflow as a typed task graph and run it against pluggable providers — Freestyle VMs, gcloud CLI, cmux sessions, and more.

## What rigkit gives you

<CardGroup cols={2}>
  <Card title="Typed task graphs" icon="diagram-project">
    Author workflows in TypeScript with type-safe inputs, outputs, and dependencies.
  </Card>
  <Card title="Provider-owned artifacts" icon="boxes-stacked">
    Providers manage their own state, credentials, and lifecycle.
  </Card>
  <Card title="Forkable workspaces" icon="code-fork">
    Branch a workspace, run experiments, and merge back without disturbing the source.
  </Card>
  <Card title="One CLI" icon="terminal">
    `rig plan`, `rig apply`, `rig run` — the same primitives across every provider.
  </Card>
</CardGroup>
