Rigkit runs development environments from a TypeScript config.

You write the setup once, Rigkit prepares it, and then you create as many named
workspaces as you need for agents, developers, CI jobs, or tests.

## Core loop

```sh
curl -fsSL https://www.rigkit.dev/install | sh
```

Create a project and bring up your first workspace:

```sh
rig init website --package-manager pnpm
cd website
rig plan --workflow dev
rig apply --workflow dev
rig create --workflow dev dev
rig run dev ssh
rig rm dev
```

- `rig plan` shows which setup tasks are cached or pending.
- `rig apply` runs pending tasks and stores their JSON `ctx`.
- `rig create --workflow <workflow> <name>` creates a workspace from the workflow output.
- `rig run <name> <operation>` runs an operation defined by `rigkit/index.ts`.
